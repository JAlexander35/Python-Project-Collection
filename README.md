
# Offensive Python Network Tools

A compact, well-organized collection of Python scripts for learning and practicing network / offensive security techniques — TCP/UDP clients & servers, simple proxies, scanners, and small utilities.

Purpose: educational, lab testing, and red-team tool development in authorized environments only.

#Legal & Safety Notice DO NOT run these tools against systems you do not own or against networks where you do not have explicit, written authorization. Misuse is illegal and unethical. These scripts are provided for education, testing in isolated labs, and authorized engagements only.


## Installation of Python env

clone the repo
git clone <your-repo-url>
cd <your-repo>

create & activate venv
python3 -m venv .venv
Linux / macOS
source .venv/bin/activate
Windows PowerShell
.venv\Scripts\Activate.ps1
Windows cmd.exe
.venv\Scripts\activate.bat

# install deps
python3 -m pip install -r requirements.txt
